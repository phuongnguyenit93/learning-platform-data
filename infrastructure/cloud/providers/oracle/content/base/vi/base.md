# Cloud Providers Oracle

Oracle Cloud Infrastructure (OCI) là nền tảng đám mây của Oracle cung cấp tài nguyên tính toán, mạng, lưu trữ, cơ sở dữ liệu và các dịch vụ quản trị để triển khai ứng dụng. Hiểu cách OCI tổ chức region, availability domain, tenancy và compartment giúp bạn xây dựng môi trường có ranh giới truy cập rõ ràng, phù hợp với yêu cầu vận hành.

Module dành cho người đã có kiến thức nền về cloud, hệ điều hành, mạng và cơ sở dữ liệu. Lộ trình bắt đầu với cấu trúc OCI và IAM, tiếp theo là thiết kế Virtual Cloud Network (VCN), khởi tạo Compute instance, lựa chọn Object/Block/File Storage và làm quen các dịch vụ Oracle Database. Các mốc cuối tập trung vào bảo mật, Monitoring, Infrastructure as Code bằng Resource Manager và quản lý chi phí.

Sau khi học, bạn có thể dựng một môi trường OCI thử nghiệm cho ứng dụng, phân quyền tối thiểu, giám sát tài nguyên và tự động hóa việc tạo hạ tầng. Khi thực hành, cần kiểm tra giới hạn dịch vụ, quyền truy cập và mức giá của region/tài khoản trước khi tạo tài nguyên có tính phí.
