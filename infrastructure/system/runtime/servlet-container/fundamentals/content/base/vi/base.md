# Runtime — Servlet Container Fundamentals

**Servlet Container** là môi trường thực thi các ứng dụng Java web theo đặc tả **Jakarta Servlet**. Container tiếp nhận yêu cầu HTTP, định tuyến đến Servlet, quản lý vòng đời đối tượng, Filter, Listener, phiên làm việc và những tài nguyên cần thiết để xử lý phản hồi. **Apache Tomcat** là một ví dụ phổ biến: các thành phần Connector, Engine, Host và Context cùng tổ chức việc nhận yêu cầu và chọn ứng dụng. Hiểu lớp runtime này giúp phân tích đường đi của request thay vì coi framework web là một hộp đen.

Module dành cho người đã biết Java, HTTP cơ bản và khái niệm web application. Bạn sẽ làm quen với kiến trúc Tomcat, viết HttpServlet, xử lý request/response, bổ sung Filter/Listener và quản lý scope, cookie, HttpSession. Tiếp đó là vấn đề thread safety khi nhiều request dùng chung Servlet, async processing, cấu trúc WAR và cách classloader cô lập ứng dụng. Cuối cùng, bạn thực hành cấu hình HTTP Connector, theo dõi log/JMX và các nguyên tắc bảo vệ container. Ví dụ có thể dùng **Jakarta Servlet 6.1 và Tomcat 11**; hãy đối chiếu phiên bản JDK/Servlet API tương thích trước khi chạy. Kết thúc lộ trình, bạn có thể triển khai một Servlet đơn giản, lần theo vòng đời request và chẩn đoán lỗi cấu hình thường gặp.
