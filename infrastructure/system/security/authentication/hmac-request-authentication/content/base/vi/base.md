# Security Authentication Hmac Request Authentication

HMAC Request Authentication là cơ chế dùng mã xác thực thông điệp dựa trên hàm băm và một khóa bí mật được chia sẻ giữa client với server để bảo vệ các thành phần đã chọn của HTTP request. Bên gửi tạo mã HMAC từ dữ liệu request đã chuẩn hóa; bên nhận sử dụng khóa tương ứng để tính lại và xác minh. Cơ chế này hỗ trợ xác nhận bên gửi có quyền sử dụng khóa và phát hiện thay đổi dữ liệu được ký, nhưng không tự mã hóa nội dung, không thay thế HTTPS hay kiểm tra phân quyền của ứng dụng.

Roadmap một cấp gồm tám mốc: hiểu HMAC và mô hình shared secret, quản lý key ID cùng vòng đời khóa, thiết kế canonical request bao phủ method, URI, query, headers và body digest. Tiếp theo, người học tạo chữ ký HMAC-SHA256 trong Java, xác minh chữ ký tại server bằng phép so sánh an toàn, áp dụng authorization độc lập rồi bảo vệ chống replay bằng timestamp, nonce và thời hạn. Mốc cuối tập trung vào test vector, các lỗi chuẩn hóa qua proxy, rotation, theo dõi lỗi và ngăn rò rỉ bí mật. Những yêu cầu cụ thể về thành phần cần ký phải thống nhất theo giao thức hai bên dùng, chẳng hạn HTTP Message Signatures hoặc một sơ đồ HMAC riêng được đặc tả rõ.

Module phù hợp với developer backend, Java engineer hoặc người tích hợp REST API đã biết HTTP, JSON và kiến thức xác thực cơ bản. Sau khi hoàn thành, bạn có thể giải thích quy trình ký và xác minh request, xây dựng bản mẫu client/server bằng Java, viết bộ kiểm thử cho request bị sửa hoặc gửi lại, và chỉ ra những đánh đổi về quản lý khóa, độ đồng bộ thời gian và tính tương thích giữa các hệ thống.
