# Database SQL

SQL (Structured Query Language) là ngôn ngữ làm việc với cơ sở dữ liệu quan hệ: truy vấn, thêm, sửa, xóa dữ liệu và định nghĩa cấu trúc bảng. Hiểu SQL giúp lập trình viên và người học dữ liệu khai thác thông tin chính xác, kết nối các thực thể và bảo vệ tính toàn vẹn dữ liệu.

Module dành cho người bắt đầu học cơ sở dữ liệu hoặc lập trình backend. Lộ trình đi từ bảng, cột và khóa đến SELECT, lọc, sắp xếp, tổng hợp với GROUP BY, kết hợp bảng bằng JOIN và tổ chức truy vấn bằng subquery/CTE. Sau đó, bạn thực hành DML, DDL, ràng buộc, giao dịch và đọc kế hoạch thực thi để nhận diện truy vấn kém hiệu quả.

Hãy dùng bộ dữ liệu khách hàng, đơn hàng và sản phẩm để viết các truy vấn thống kê doanh thu, liệt kê đơn hàng và cập nhật trạng thái có kiểm soát. Ví dụ trong tài liệu tham khảo ưu tiên PostgreSQL; cú pháp của một số câu lệnh có thể khác ở MySQL, SQLite hoặc các hệ quản trị khác. Kết thúc module, bạn có thể tự thiết kế câu lệnh SQL cơ bản, kiểm tra kết quả và nhận biết các rủi ro thường gặp khi thao tác dữ liệu.
