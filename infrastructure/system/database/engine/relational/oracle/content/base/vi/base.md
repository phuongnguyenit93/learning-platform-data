# Database Engine Relational Oracle

**Oracle Database** là hệ quản trị cơ sở dữ liệu quan hệ phục vụ những hệ thống cần truy vấn SQL, quản lý giao dịch đồng thời, bảo mật và vận hành dữ liệu ổn định. Học phần tập trung vào cách Oracle tổ chức database và instance, mô hình multitenant, schema, cùng các tính năng đặc trưng như PL/SQL, read consistency và tối ưu hóa truy vấn.

Lộ trình gồm **8 mốc**: kiến trúc và kết nối Oracle; thiết kế schema bằng DDL; truy vấn Oracle SQL; transaction và locking; lập trình PL/SQL; index và optimizer; users và privileges; cuối cùng là vận hành cùng backup/recovery. Người học thực hành trên một PDB thử nghiệm, đi từ tạo bảng và truy vấn đến quan sát execution plan, phân quyền và đánh giá tình huống khôi phục dữ liệu.

Học phần phù hợp với người đã có nền tảng SQL và mô hình dữ liệu quan hệ. Sau khi hoàn thành, bạn có thể xây dựng schema Oracle nhỏ, viết và kiểm thử truy vấn, hiểu tác động của transaction khi nhiều phiên cùng làm việc, sử dụng PL/SQL cơ bản và nhận diện các công cụ thiết yếu để quản trị, tối ưu và bảo vệ dữ liệu.
