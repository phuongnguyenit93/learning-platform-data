# Programming Paradigm — Dataflow Programming

Dataflow Programming là cách tổ chức chương trình quanh **dòng dữ liệu và các quan hệ phụ thuộc giữa phép tính**. Thay vì mô tả chi tiết thứ tự từng lệnh hoặc thread, lập trình viên biểu diễn những thao tác cần thực hiện, dữ liệu mà chúng nhận và kết quả chúng tạo ra. Một node chỉ có thể xử lý khi các đầu vào cần thiết đã sẵn sàng; các node không phụ thuộc nhau có cơ hội chạy song song. Mô hình này thường được hình dung bằng đồ thị có hướng và được dùng trong xử lý dữ liệu, pipeline bất đồng bộ và một số hệ thống tính toán đồ thị.

Module phù hợp với người đã nắm lập trình Java, cấu trúc dữ liệu, hàm và các khái niệm đồng thời cơ bản. Bạn sẽ bắt đầu bằng việc so sánh dataflow với control flow, vẽ đồ thị node–edge từ một biểu thức, rồi thực hành các phép biến đổi dữ liệu như map, filter, aggregate. Lộ trình tiếp tục với cách ghép các bước thành pipeline, tách nhánh và hợp nhất dữ liệu, giải thích quy tắc scheduling theo dependency thay vì giả định mọi bước đều chạy tuần tự. Với đồ thị không chu trình (DAG), thứ tự topo thể hiện các quan hệ bắt buộc; hệ thống có trạng thái hoặc vòng lặp cần cơ chế xử lý riêng.

Phần ứng dụng phân biệt dữ liệu batch hữu hạn với stream liên tục, giới thiệu buffering, backpressure và windowing. Bạn sẽ xây pipeline Java với Apache Beam qua `PCollection` và `PTransform`, đồng thời biết Java `Flow` giải quyết trao đổi dữ liệu bất đồng bộ có kiểm soát nhu cầu. Cuối cùng, các kiểm thử `TestPipeline`/`PAssert` và việc quan sát độ trễ, throughput giúp kiểm chứng kết quả và tìm nút thắt. Hoàn thành module, bạn có thể thiết kế, đọc và đánh giá một dataflow graph nhỏ, xác định các phụ thuộc, khả năng song song và đánh đổi khi triển khai.
