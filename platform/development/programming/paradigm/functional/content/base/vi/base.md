# Programming Paradigm Functional

Functional Programming (lập trình hàm) là một cách tổ chức chương trình xoay quanh **hàm và phép biến đổi dữ liệu**. Thay vì để nhiều thành phần cùng thay đổi trạng thái ẩn, phong cách này ưu tiên hàm thuần (*pure function*), dữ liệu bất biến (*immutability*) và khả năng ghép các hàm nhỏ thành luồng xử lý. Những nguyên tắc đó giúp dễ kiểm thử và suy luận hành vi, nhưng không có nghĩa mọi thao tác thực tế đều tránh được I/O hoặc mọi ngôn ngữ phải theo lập trình hàm thuần túy.

Module dành cho người học đã nắm cơ bản về hàm, kiểu dữ liệu, collection và Java hoặc một ngôn ngữ tương đương. Lộ trình bắt đầu bằng so sánh phong cách imperative với functional, sau đó thực hành pure function, referential transparency và cập nhật immutable data. Bạn sẽ sử dụng lambda, first-class function, higher-order function và function composition để viết pipeline `map`–`filter`–`reduce`; tiếp theo là recursion, cách biểu diễn dữ liệu thiếu/lỗi bằng `Option` hoặc `Either` và mô hình đại số dữ liệu (ADT). Ví dụ có thể được triển khai bằng Java `Function`, `Predicate`, `Stream`, `Optional` hoặc đối chiếu với Scala để làm rõ khái niệm.

Bài thực hành đề xuất là xử lý danh sách đơn hàng: lọc bản ghi hợp lệ, tính toán giá trị và tổng hợp doanh thu bằng các hàm không làm thay đổi dữ liệu nguồn. Hãy viết test cho danh sách rỗng, giá trị thiếu và dữ liệu đầu vào không hợp lệ; sau đó tách phần lấy dữ liệu/ghi kết quả khỏi lõi tính toán. Kết thúc module, bạn có thể nhận diện hàm thuần, chọn cấu trúc dữ liệu thích hợp và áp dụng tư duy functional thực dụng khi xây dựng phần mềm.
