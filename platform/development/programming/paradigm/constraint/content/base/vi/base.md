# Programming Paradigm Constraint

Constraint Programming (lập trình ràng buộc) là cách giải bài toán bằng việc mô tả những điều kiện mà lời giải phải thỏa mãn, thay vì tự lập trình toàn bộ trình tự tìm kiếm. Một bài toán thỏa mãn ràng buộc (Constraint Satisfaction Problem — CSP) thường gồm tập biến, miền giá trị của từng biến và các ràng buộc liên hệ giữa chúng. Solver sử dụng kỹ thuật suy diễn, thu hẹp miền, tìm kiếm và quay lui để tìm phép gán hợp lệ. Phương pháp này hữu ích cho phân công công việc, xếp lịch, phân bổ tài nguyên, bài toán logic và các vấn đề có nhiều tổ hợp lựa chọn.

Roadmap một cấp gồm tám mốc: nắm tư duy CSP, mô hình hóa biến và miền giá trị, biểu diễn các ràng buộc cơ bản rồi tìm hiểu propagation và backtracking. Người học áp dụng kiến thức vào bài toán phân công hoặc xếp lịch, phân biệt tìm nghiệm khả thi với tối ưu hóa theo objective và các ưu tiên mềm. Tiếp đó là thực hành Java với Choco Solver hoặc Google OR-Tools CP-SAT, rồi kiểm thử mô hình, phát hiện ràng buộc mâu thuẫn và giới hạn thời gian chạy. Cần lưu ý CP-SAT của OR-Tools dùng mô hình biến và biểu thức nguyên; các lựa chọn solver khác có thể hỗ trợ loại biến và cơ chế giải khác nhau.

Module phù hợp với người đã học điều kiện, vòng lặp, cấu trúc dữ liệu và Java cơ bản, muốn tiếp cận lối giải bài toán mang tính khai báo. Sau khi hoàn thành, bạn có thể chuyển yêu cầu thành mô hình biến–miền–ràng buộc, tạo và xác minh nghiệm, so sánh hard constraint với mục tiêu tối ưu, đồng thời sử dụng thư viện Java để giải một bài toán CSP nhỏ và đánh giá giới hạn của mô hình khi độ phức tạp tăng.
