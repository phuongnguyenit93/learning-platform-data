# Java 17

Module này dành cho người đã nắm cú pháp Java, lập trình hướng đối tượng và xử lý ngoại lệ, muốn hiểu những thay đổi ổn định của Java 17 còn hữu ích trong thực tế. Phạm vi tập trung vào sealed classes, API sinh số giả ngẫu nhiên, ngữ nghĩa số thực nhất quán, đóng gói mạnh của JDK và cơ chế lọc giải tuần tự theo ngữ cảnh khi ứng dụng có nhu cầu xử lý luồng đối tượng.

Tư duy xuyên suốt là mô hình hóa rõ ràng, sử dụng API công khai và kiểm chứng hành vi bằng những ví dụ nhỏ. Người học thực hành kiểm soát kế thừa, tạo dữ liệu ngẫu nhiên có thể tái lập cho kiểm thử, hiểu giới hạn của phép tính số thực và kiểm soát dữ liệu được giải tuần tự.

Lộ trình bắt đầu bằng thiết lập môi trường Java 17, tiếp nối với các đặc tính ngôn ngữ và thư viện, rồi đi vào ranh giới truy cập cùng bộ lọc dữ liệu. Cuối module, người học cập nhật cấu hình build và thư viện của một ứng dụng nhỏ, chạy kiểm thử hồi quy và xử lý các vấn đề tương thích để xác nhận ứng dụng hoạt động đúng trên Java 17.
