# Spring Data MongoDB

**Spring Data MongoDB** là mô-đun thuộc hệ sinh thái Spring Data giúp ứng dụng Java thao tác với cơ sở dữ liệu tài liệu MongoDB thông qua repository và MongoTemplate. Học phần tập trung vào cách kết nối, ánh xạ đối tượng Java sang document, truy vấn và cập nhật dữ liệu, đồng thời giải thích những lựa chọn ảnh hưởng đến tính đúng đắn và hiệu năng.

Lộ trình gồm **8 mốc**: kết nối và cấu hình; ánh xạ document; MongoDB repositories; thao tác CRUD với MongoTemplate; aggregation pipeline; index và hiệu năng; transaction và tính nhất quán; cuối cùng là truy cập reactive và kiểm thử. Người học sẽ đi từ các thao tác dữ liệu cơ bản đến các bài toán cần truy vấn linh hoạt, tổng hợp dữ liệu, tối ưu hóa và quản lý cập nhật đồng thời.

Học phần phù hợp với người đã biết Java, Spring Boot và khái niệm cơ bản về MongoDB. Sau khi hoàn thành, bạn có thể chọn Repository hoặc MongoTemplate cho từng tình huống, xây dựng truy vấn có kiểm chứng, hiểu ranh giới transaction, phân biệt truy cập đồng bộ với reactive và viết kiểm thử cho lớp lưu trữ.
