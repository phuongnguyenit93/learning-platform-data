# Spring Cloud Provider Integration

**Spring Cloud Provider Integration** tập trung vào cách ứng dụng Java/Spring Boot kết nối với dịch vụ managed của các nhà cung cấp cloud như AWS, Microsoft Azure và Google Cloud. Các dự án Spring Cloud AWS, Spring Cloud Azure và Spring Framework on Google Cloud cung cấp starter, auto-configuration và các thành phần tích hợp cho storage, messaging, secrets hoặc data services. Tuy nhiên, mỗi nền tảng có mô hình định danh, quyền truy cập, đặc tính dịch vụ và mức hỗ trợ thư viện riêng; không nên giả định một API sẽ hoạt động giống hệt trên mọi provider.

Module dành cho lập trình viên backend/DevOps đã quen Spring Boot, dependency management và REST hoặc messaging cơ bản. Lộ trình bắt đầu bằng so sánh dịch vụ cloud và chọn đúng Spring Boot/Spring Cloud/provider BOM, tiếp đến là authentication, IAM, profile và secret management. Bạn sẽ làm quen với object storage, queue/pub-sub và managed database, rồi bổ sung timeout, retry có giới hạn, idempotency và quan sát bằng Actuator/Micrometer. Phần thực hành hướng đến cấu hình theo môi trường và sử dụng managed/workload identity thay cho khóa bí mật gắn cứng trong source code.

Hãy chọn **một** nhà cung cấp cloud và xây ứng dụng Spring mẫu có thao tác upload file, gửi hoặc nhận message và đọc một cấu hình bí mật trên môi trường được cấp phép. Kiểm thử trường hợp thiếu quyền, mất kết nối hoặc nhận message trùng; chạy test bằng emulator/sandbox nếu có và xác minh bằng môi trường cloud thử nghiệm trước khi triển khai. Kết thúc module, bạn có thể chọn starter phù hợp, giải thích ranh giới bảo mật và vận hành tích hợp cloud có kiểm soát.
