# Data Processing

Data Processing (xử lý dữ liệu) là quá trình biến dữ liệu đầu vào thành kết quả có ý nghĩa qua một chuỗi bước rõ ràng, gọi là *pipeline*. Module này dành cho người học Java đã nắm cấu trúc dữ liệu cơ bản và muốn thiết kế các quy trình xử lý dễ hiểu, dễ kiểm thử, có thể mở rộng khi dữ liệu tăng lên.

Bạn sẽ bắt đầu từ cách tổ chức pipeline, sau đó thực hành lọc, biến đổi, nhóm và tổng hợp dữ liệu bằng Java Stream API. Tiếp theo, module giới thiệu hai mô hình quan trọng: xử lý theo lô (*batch*) với các bước đọc–xử lý–ghi, và xử lý luồng (*streaming*) với cửa sổ thời gian cùng trạng thái. Cuối lộ trình là cách đo hiệu năng, cân nhắc song song hóa, kiểm thử và phục hồi khi có lỗi.

Sau khi học, bạn có thể phác thảo một pipeline, chọn cách xử lý phù hợp với đặc điểm dữ liệu, giải thích các phép biến đổi và đánh giá kết quả qua kiểm thử cùng số liệu quan sát.
