# Data Persistence Relational Access JDBC

JDBC (Java Database Connectivity) là API tiêu chuẩn để ứng dụng Java giao tiếp với cơ sở dữ liệu quan hệ thông qua driver và câu lệnh SQL. Nắm vững JDBC giúp bạn hiểu trực tiếp cách mở kết nối, truyền tham số, nhận kết quả và kiểm soát giao dịch, đồng thời có nền tảng để đánh giá các công cụ truy cập dữ liệu ở tầng cao hơn.

Module dành cho người đã biết Java cơ bản và SQL như SELECT, INSERT, UPDATE, DELETE. Lộ trình bắt đầu từ kiến trúc JDBC, kết nối bằng DataSource, PreparedStatement và ResultSet; sau đó chuyển sang CRUD, khóa sinh, transaction, hiệu năng, quản lý tài nguyên và xử lý lỗi.

Cuối lộ trình, bạn sẽ thực hiện một chức năng CRUD hoàn chỉnh với JDBC, kiểm thử kết quả trong cơ sở dữ liệu và chứng minh thao tác rollback khi có lỗi. Trọng tâm là viết SQL có tham số an toàn, sử dụng kết nối đúng vòng đời và giải thích được hành vi của mỗi thao tác.
