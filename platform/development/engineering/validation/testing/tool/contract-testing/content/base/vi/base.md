# Engineering Validation Testing Tool Contract Testing

Contract Testing là kỹ thuật kiểm thử nhằm xác nhận hai thành phần giao tiếp với nhau theo một hợp đồng chung: phía consumer gửi đúng yêu cầu và phía provider trả về dữ liệu, trạng thái hoặc thông điệp mà consumer đang phụ thuộc. Khi các service phát triển và triển khai độc lập, những thay đổi nhỏ ở trường JSON, HTTP header, mã lỗi hay định dạng message có thể làm hỏng tích hợp dù từng service vẫn vượt qua unit test. Contract test cung cấp phản hồi nhanh về tính tương thích, nhưng không thay thế việc kiểm thử toàn bộ hành vi nghiệp vụ, bảo mật hay hiệu năng.

Module phù hợp với người đã có nền tảng Java, HTTP/JSON, JUnit, Spring Boot và kiểm thử tích hợp cơ bản. Lộ trình bắt đầu từ khái niệm consumer–provider và đặc tả request/response, sau đó xây dựng consumer test bằng Pact JVM, thực hiện provider verification với trạng thái dữ liệu kiểm thử phù hợp và viết matching rule tránh phụ thuộc vào giá trị ngẫu nhiên. Người học cũng tìm hiểu Spring Cloud Contract với DSL, generated verification test và Stub Runner; cuối cùng là xuất bản contract lên Pact Broker, tích hợp kiểm tra can-i-deploy vào CI/CD và đánh giá thay đổi API có còn tương thích hay không.

Sau khi hoàn thành, bạn có thể viết một bộ contract test cho client Java và API provider, giải thích vì sao kiểm thử consumer và provider cần chạy ở hai phía, quản lý pact file cùng kết quả xác minh và thiết kế cổng kiểm tra trước triển khai. Hợp đồng nên phản ánh những dữ liệu consumer thực sự sử dụng, không cố chép toàn bộ response; với public API hoặc hệ thống khó kiểm soát provider state, cần cân nhắc thêm schema testing và integration test phù hợp.
