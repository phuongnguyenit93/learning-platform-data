# Checkstyle — Kiểm tra quy ước mã Java

Checkstyle là công cụ phân tích tĩnh giúp kiểm tra mã nguồn Java theo các quy ước đã cấu hình, chẳng hạn cách đặt tên, import, khoảng trắng và Javadoc. Công cụ chỉ ra những vị trí vi phạm để người phát triển xem xét và sửa; Checkstyle không thay thế kiểm thử hoặc công cụ tự động định dạng mã.

Module dành cho người học Java muốn xây dựng tiêu chuẩn viết mã thống nhất trong dự án. Bạn sẽ đi từ tổng quan và cách chạy Checkstyle đến cấu hình XML, lựa chọn các nhóm quy tắc, đọc và xử lý vi phạm, quản lý ngoại lệ rồi tích hợp kiểm tra vào Gradle và CI. Kết thúc lộ trình, bạn có thể tự thiết lập một bộ quy tắc gọn, giải thích kết quả kiểm tra và duy trì chất lượng mã trong nhóm.
