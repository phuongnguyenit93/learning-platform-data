# Code Quality — Coding Standards

Coding Standards là tập hợp những quy ước giúp mã Java nhất quán, dễ đọc, dễ review và thuận tiện bảo trì khi nhiều người cùng phát triển. Các quy tắc thường bao gồm cách đặt tên, tổ chức tệp nguồn, định dạng, chú thích và cách trình bày ý định của mã. Mục tiêu là giảm khác biệt tùy hứng, đồng thời giữ lại những lựa chọn hợp lý theo ngữ cảnh dự án.

Module này dành cho người học Java và các thành viên nhóm muốn xây dựng một chuẩn viết mã chung. Bạn sẽ học từ nền tảng của coding standards, áp dụng quy ước tên và cấu trúc tệp, rèn cách trình bày và viết mã dễ hiểu, soạn comment/Javadoc có ích, rồi thiết lập tiêu chí review và kiểm tra với các công cụ hỗ trợ. Kết thúc lộ trình, bạn có thể đọc, đánh giá và cải thiện mã theo một bộ tiêu chí nhất quán.
