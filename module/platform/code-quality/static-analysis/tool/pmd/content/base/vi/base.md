# PMD — Công cụ phân tích mã tĩnh

PMD là công cụ phân tích mã nguồn tĩnh, giúp phát hiện các vấn đề tiềm ẩn về chất lượng mã thông qua hệ thống quy tắc (rules). Ngoài việc nhận diện những đoạn mã cần xem xét, bộ công cụ còn có CPD để tìm mã trùng lặp. PMD bổ sung góc nhìn về cấu trúc và cách viết mã cho quá trình kiểm thử và review.

Module này dành cho người học Java muốn áp dụng PMD vào dự án thực tế. Bạn sẽ bắt đầu từ cách chạy công cụ, xây dựng ruleset vừa đủ, đọc và xử lý cảnh báo, đánh giá mã lặp bằng CPD, rồi tích hợp kiểm tra vào Gradle và CI. Sau lộ trình, bạn có thể duy trì các quy tắc chất lượng rõ ràng và xử lý kết quả phân tích một cách có chủ đích.
