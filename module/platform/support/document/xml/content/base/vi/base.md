# Support Document XML

XML (*Extensible Markup Language*) là định dạng văn bản có cấu trúc, thường dùng để lưu trữ và trao đổi tài liệu giữa các hệ thống. Module **Support Document XML** giúp người học hiểu cú pháp, cấu trúc phân cấp, namespace và cách đọc hoặc tạo tài liệu XML trong ứng dụng Java bằng các API xử lý XML phổ biến.

Lộ trình gồm tám mốc: cú pháp XML và well-formedness, namespace, phân tích cú pháp với DOM/SAX/StAX, truy vấn XPath, xác thực bằng XSD, sinh và biến đổi XML, xử lý dữ liệu không tin cậy an toàn, cuối cùng là kiểm thử và tích hợp. Trọng tâm là chọn cách xử lý phù hợp với kích thước và hợp đồng của tài liệu, thay vì chỉ đọc được một tệp XML mẫu.

Module phù hợp với lập trình viên đã biết Java, cấu trúc dữ liệu dạng cây và thao tác tệp cơ bản. Sau khi hoàn thành, bạn có thể đọc và xuất XML, trích xuất dữ liệu bằng XPath, xác thực theo schema, nhận diện nguy cơ XXE và xây dựng kiểm thử cho tài liệu lỗi hoặc không tương thích.
