# Data Persistence Relational Access ORM Hibernate

Hibernate ORM giúp ứng dụng Java lưu và truy vấn đối tượng trên cơ sở dữ liệu quan hệ mà không phải tự viết toàn bộ thao tác ánh xạ SQL/JDBC. Module tập trung vào Hibernate ORM, từ cấu hình và ánh xạ entity đến làm việc với session, giao dịch và truy vấn; đồng thời làm rõ cách Hibernate triển khai Jakarta Persistence (JPA) và cung cấp các API riêng.

Lộ trình phù hợp với người đã biết Java cơ bản, SQL và mô hình bảng/khóa quan hệ. Bạn sẽ bắt đầu từ SessionFactory, Session và cấu hình kết nối; tiếp theo thực hành entity mapping, quan hệ, trạng thái entity, transaction, HQL và Criteria. Các phần cuối giúp phát hiện N+1, tận dụng cache hợp lý, khóa lạc quan và đọc SQL log để xử lý sự cố.

Sau module, bạn có thể xây dựng luồng lưu/đọc dữ liệu bằng Hibernate, giải thích hành vi tải và đồng bộ entity, lựa chọn cách truy vấn phù hợp và kiểm tra các vấn đề thường gặp về hiệu năng hoặc tính nhất quán.
