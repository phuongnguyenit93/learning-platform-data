# Data Persistence Relational Access MyBatis

MyBatis là framework SQL Mapper giúp ứng dụng Java truy cập cơ sở dữ liệu quan hệ bằng những câu SQL do lập trình viên chủ động định nghĩa. Framework đảm nhiệm việc gắn tham số, thực thi câu lệnh và ánh xạ kết quả về đối tượng; người học vẫn cần hiểu SQL và cách dữ liệu quan hệ được tổ chức để sử dụng hiệu quả.

Module dành cho người đã biết Java, SQL cơ bản và khái niệm giao dịch. Nội dung bắt đầu với cấu trúc MyBatis và vòng đời `SqlSession`, sau đó đi qua Mapper, các thao tác CRUD, bind tham số an toàn, `resultMap` và quan hệ dữ liệu, SQL động, giao dịch cùng tích hợp Spring Boot. Trọng tâm là hiểu cơ chế hoạt động và cách kiểm soát SQL, không phụ thuộc vào một bộ bảng dữ liệu hay ứng dụng mẫu cụ thể.

Qua tám mốc học, bạn sẽ biết thiết lập luồng truy cập dữ liệu với MyBatis, viết Mapper có kiểm soát, đọc và ánh xạ kết quả phức tạp, xử lý giao dịch, đồng thời kiểm thử và phát hiện những vấn đề hiệu năng thường gặp.
