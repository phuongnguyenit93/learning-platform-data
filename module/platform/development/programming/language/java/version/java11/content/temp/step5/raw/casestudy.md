Nền tảng đào tạo soạn tài liệu minh họa Java 11 nhưng thử nghiệm trên JDK hiện tại có thêm method String và Files mới hơn, khiến bài tập không còn chạy trên mức Java 11 mục tiêu; nhóm kỹ thuật cần xác định tập API thực sự thuộc phiên bản dạy.
Doanh nghiệp thương mại dùng java.net.http.HttpClient trong một service mới và xem việc bỏ thư viện ngoài là đủ để tương thích mọi Java runtime, nhưng một môi trường vẫn dùng JDK 8 không có module HTTP Client chuẩn; nhóm triển khai cần đánh giá điều kiện phiên bản tối thiểu.
