Ngân hàng điều tra lỗi mất cập nhật bằng log có synchronized trên cùng khóa mà code đang thiếu, khiến khi bật ghi log sự cố biến mất và đội kỹ thuật không thể tái hiện; nhóm phát triển cần đánh giá tác động của công cụ quan sát lên lịch thực thi.
