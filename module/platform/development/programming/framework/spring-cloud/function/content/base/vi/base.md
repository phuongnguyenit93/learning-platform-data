# Spring Cloud Function

**Spring Cloud Function** giúp xây dựng logic nghiệp vụ bằng các hàm Java và tái sử dụng cùng một cách xử lý trên nhiều môi trường thực thi, chẳng hạn HTTP endpoint, luồng sự kiện qua broker hoặc nền tảng *Function as a Service* (FaaS). Thay vì gắn logic trực tiếp vào một controller hay cơ chế truyền tải, lập trình viên định nghĩa các bean dạng `Supplier<T>`, `Function<I, O>` và `Consumer<T>`; Spring Cloud Function bổ sung `FunctionCatalog`, chuyển đổi dữ liệu, composition và các runtime adapter.

Module dành cho người đã nắm Java, Spring Boot, Dependency Injection và kiến thức cơ bản về HTTP hoặc message broker. Bạn sẽ bắt đầu bằng việc thiết kế một function thuần nghiệp vụ, khai báo functional bean, truy xuất qua `FunctionCatalog` và ghép nhiều hàm bằng `spring.cloud.function.definition`. Tiếp theo là routing, xuất function dưới dạng HTTP endpoint, tích hợp Spring Cloud Stream để xử lý thông điệp và nhận diện khác biệt giữa hàm imperative với hàm reactive sử dụng `Flux`/`Mono`. Các mốc cuối giới thiệu cách đóng gói, chạy trên serverless adapter như AWS Lambda và kiểm thử từ logic độc lập đến adapter thực tế.

Sau tám mốc, bạn có thể xây dựng và kiểm thử một luồng xử lý có thể chuyển đổi giữa môi trường local, HTTP, messaging và serverless với ít thay đổi ở logic cốt lõi. **Spring Cloud Function Web Adapter không thay thế đầy đủ Spring MVC/WebFlux**; nên chọn nó khi cần biểu diễn các tác vụ chức năng đơn giản. Đồng thời, routing expression có thể tạo rủi ro nếu lấy từ đầu vào không tin cậy, và khi chạy thực tế vẫn cần kiểm soát quyền, secret, lỗi, độ trễ và phiên bản framework phù hợp.
