# Spring Cloud Kubernetes

**Spring Cloud Kubernetes** cung cấp các tích hợp giữa Spring Cloud và nền tảng Kubernetes cho ứng dụng Java/Spring Boot, chẳng hạn như `DiscoveryClient`, nạp cấu hình từ `ConfigMap` hoặc `Secret`, cân bằng tải phía client và thông báo thay đổi cấu hình. Đây là các tiện ích **tùy nhu cầu**, không phải điều kiện bắt buộc để triển khai Spring Boot trên Kubernetes: một ứng dụng có thể chạy tốt với `Deployment`, `Service` và DNS của Kubernetes mà không cần thêm starter. Module phù hợp với người đã nắm Spring Boot, Docker, HTTP và kiến thức Kubernetes về Pod, Service, namespace.

Lộ trình bắt đầu từ vai trò của Spring Cloud Kubernetes và cách chọn dependency phù hợp với phiên bản Spring Boot/Spring Cloud, sau đó đóng gói, triển khai ứng dụng và kiểm tra rollout. Người học tiếp tục nạp cấu hình bằng `spring.config.import`, phân biệt `ConfigMap` với `Secret`, rồi sử dụng `DiscoveryClient` và Spring Cloud `LoadBalancer` để tìm và gọi các service. Các mốc tiếp theo giải thích **Configuration Watcher**: giá trị cấu hình được cập nhật trên volume không đồng nghĩa Spring tự refresh, nên cần cơ chế phát sự kiện hoặc làm mới ứng dụng thích hợp. Cuối cùng, người học cấu hình `ServiceAccount` cùng RBAC tối thiểu, health probes của Spring Boot Actuator, scale replicas và kiểm thử khi deploy.

Kết thúc module, bạn có thể triển khai một ứng dụng Spring Boot lên cluster thử nghiệm, biết khi nào dùng Kubernetes Service DNS thay cho DiscoveryClient, hiểu cách cấu hình và cập nhật runtime, đồng thời xác định quyền API thực sự cần cấp. Khi vận hành, hãy **không cấp quyền cluster-wide theo thói quen** và không công khai endpoint quản trị/refresh. Kiểm tra compatibility matrix trước khi chọn phiên bản thư viện; đo lường logs, readiness và quá trình rollout để phát hiện sự cố thay vì chỉ dựa vào trạng thái Pod đang chạy.
