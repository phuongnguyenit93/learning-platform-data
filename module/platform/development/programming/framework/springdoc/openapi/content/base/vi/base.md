# Springdoc Openapi

Springdoc OpenAPI là thư viện giúp ứng dụng Spring Boot tự động tạo đặc tả OpenAPI từ controller, cấu hình, kiểu dữ liệu và annotation. Đặc tả này có thể được xuất dưới dạng JSON/YAML để công cụ khác sử dụng, đồng thời được trình bày qua Swagger UI để lập trình viên và bên tích hợp khám phá, thử nghiệm API. Việc có tài liệu chuẩn giúp các nhóm hiểu hợp đồng API và phát hiện sai khác giữa mô tả với hành vi triển khai.

Module **Springdoc Openapi** hướng dẫn lựa chọn starter tương thích với Spring Boot và Spring Web MVC/WebFlux; truy cập API docs và Swagger UI; bổ sung mô tả operation, parameter, response, schema và validation. Người học cũng thực hành chia nhóm tài liệu, khai báo yêu cầu xác thực như bearer token/OAuth2, tùy chỉnh nội dung và cấu hình hiển thị, rồi kiểm tra tài liệu trước khi phát hành. Với Spring Boot 3, chọn nhánh springdoc-openapi 2.x; với Spring Boot 4, chọn nhánh 3.x theo tài liệu dự án.

Module phù hợp với lập trình viên Java/Spring đã hiểu HTTP và REST API. Kết thúc lộ trình, bạn có thể tạo tài liệu API rõ ràng, đọc và xác minh đặc tả đã sinh, tổ chức tài liệu cho nhiều nhóm endpoint và đưa kiểm tra tài liệu vào quy trình phát triển.
