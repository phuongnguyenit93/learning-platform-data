# Spring AI Memory Advisors

**Spring AI Memory Advisors** là các thành phần gắn vào `ChatClient` để tự động đưa ngữ cảnh từ những lượt trao đổi trước vào yêu cầu mới gửi đến mô hình ngôn ngữ. Mô hình chat về cơ bản không tự duy trì trạng thái giữa các lời gọi; Spring AI cung cấp `ChatMemory` để quyết định những tin nhắn nào nên được giữ lại và `ChatMemoryRepository` để lưu chúng. **Chat memory không đồng nghĩa với toàn bộ chat history**: nếu cần nhật ký đầy đủ cho audit hay tra cứu, nên thiết kế kho lịch sử riêng. Module hướng đến lập trình viên Java/Spring Boot đã biết `ChatClient`, dependency injection và luồng gọi API AI.

Lộ trình bắt đầu từ vai trò của Advisor và cách đăng ký `MessageChatMemoryAdvisor` bằng `defaultAdvisors()`. Người học truyền **`ChatMemory.CONVERSATION_ID` trên từng request** để quản lý các cuộc hội thoại độc lập, rồi cấu hình `MessageWindowChatMemory` nhằm giới hạn lượng ngữ cảnh. Tiếp theo là chọn repository lưu trong bộ nhớ hoặc lưu bền bằng JDBC/Redis, tìm hiểu `VectorStoreChatMemoryAdvisor` để truy xuất ký ức theo ngữ nghĩa và phân tích thứ tự advisor trong pipeline khi kết hợp memory với những chức năng như RAG, logging hay streaming. Những lựa chọn này phải phù hợp phiên bản Spring AI đang dùng; tài liệu Spring AI 2.0 yêu cầu conversation ID tường minh cho memory advisors.

Kết thúc module, bạn có thể xây dựng một chatbot Java có nhớ ngữ cảnh theo conversation ID, thử tắt/mở ứng dụng để kiểm tra persistence và đánh giá hiệu quả bằng câu hỏi nhiều lượt. Khi triển khai nhiều người dùng, phải gắn ID với quyền truy cập thực tế, không tin ID do client cung cấp mà chưa kiểm tra; cần kiểm soát lưu giữ, xóa dữ liệu và nội dung xuất hiện trong logs/traces. Lưu ý một số repository, như JDBC, không lưu các tin nhắn tool call; hãy kiểm tra giới hạn đó trước khi dùng memory để tái dựng đầy đủ luồng agent.
