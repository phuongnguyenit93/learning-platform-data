# Spring Integration Core

Spring Integration mở rộng mô hình lập trình Spring để kết nối các thành phần ứng dụng bằng thông điệp và những mẫu tích hợp doanh nghiệp (Enterprise Integration Patterns). Module này giới thiệu các khái niệm nền tảng để thiết kế luồng xử lý tách biệt giữa nơi tạo thông điệp, đường truyền và nơi thực thi nghiệp vụ. Trọng tâm là hiểu cơ chế hoạt động của framework trước khi đi sâu vào các adapter, giao thức và vận hành nâng cao.

Lộ trình một cấp gồm tám mốc, từ kiến trúc luồng và cấu trúc Message đến MessageChannel, endpoint, gateway và mô hình request/reply. Tiếp đó, người học lắp ghép IntegrationFlow bằng Java DSL, làm quen những thao tác biến đổi và định tuyến cơ bản, cuối cùng kiểm tra cách xử lý lỗi và thử nghiệm một luồng tích hợp nhỏ.

Module phù hợp với người đã biết Java và các khái niệm Spring cơ bản. Sau khi học, bạn có thể đọc và thiết kế một message flow đơn giản, phân biệt các kiểu channel, kết nối handler qua gateway hoặc Java DSL, đồng thời kiểm chứng đầu ra và tình huống lỗi bằng bài kiểm thử.
