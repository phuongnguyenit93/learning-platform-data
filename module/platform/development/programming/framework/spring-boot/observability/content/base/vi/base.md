# Spring Boot Observability

Observability giúp hiểu điều gì đang diễn ra bên trong một ứng dụng Spring Boot thông qua ba nguồn tín hiệu chính: logs, metrics và traces. Khi kết hợp các tín hiệu, bạn có thể phát hiện sự cố, tìm nguyên nhân gây chậm hoặc lỗi và đánh giá sức khỏe hệ thống khi vận hành.

Module này phù hợp với lập trình viên Java và người vận hành dịch vụ Spring Boot đã biết cách xây dựng ứng dụng cơ bản. Lộ trình đi từ nền tảng observability, Spring Boot Actuator và Micrometer đến đo metric, tạo observation riêng, gắn ngữ cảnh cho log, triển khai distributed tracing và đưa dữ liệu ra dashboard. Bạn cũng sẽ học cách đặt cảnh báo và sử dụng tín hiệu để chẩn đoán sự cố.

Hãy thực hành trên một API nhỏ: bật health và metrics, theo dõi thời gian phản hồi, tạo observation cho nghiệp vụ, liên kết log với trace, sau đó quan sát kết quả trên backend phù hợp. Kết thúc module, bạn có thể thiết lập bộ quan sát cơ bản và sử dụng logs, metrics, traces để giải thích hành vi ứng dụng.
