# Spring Data REST

**Spring Data REST** giúp xây dựng API REST từ các Spring Data repository, tự cung cấp tài nguyên HTTP cho mô hình dữ liệu và hỗ trợ điều hướng bằng hypermedia. Học phần tập trung vào cách một repository trở thành API có thể khám phá, những hành vi HTTP mặc định và các điểm cần kiểm soát khi công khai dữ liệu.

Lộ trình gồm **8 mốc**: xuất bản repository; thao tác HTTP CRUD; HAL và HATEOAS; phân trang và tìm kiếm; quan hệ và projections; cấu hình REST; validation và events; cuối cùng là bảo mật và kiểm thử. Người học sẽ thực hành với entity và repository mẫu, quan sát phản hồi HTTP, tùy biến tài nguyên hiển thị và xác minh các quy tắc truy cập.

Học phần phù hợp với người đã biết Java, Spring Boot và kiến thức cơ bản về Spring Data repository. Sau khi hoàn thành, bạn có thể thiết kế một API Spring Data REST nhỏ, hiểu cách khám phá và thao tác tài nguyên, cấu hình phạm vi công khai và kiểm thử các tình huống CRUD, validation cũng như phân quyền.
