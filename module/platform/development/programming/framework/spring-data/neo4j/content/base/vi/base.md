# Spring Data Neo4j

Spring Data Neo4j giúp ứng dụng Java và Spring Boot làm việc với cơ sở dữ liệu đồ thị Neo4j bằng các entity, repository và công cụ truy vấn theo phong cách Spring Data. Thay vì chỉ lưu bản ghi trong bảng, bạn mô hình hóa node, relationship và thuộc tính của chúng, phù hợp với những miền dữ liệu có nhiều liên kết.

Module dành cho người đã biết Java, Spring Boot và các thao tác dữ liệu cơ bản. Lộ trình mở đầu bằng nền tảng đồ thị và cấu hình kết nối, sau đó ánh xạ node cùng relationship, xây dựng repository CRUD, viết truy vấn Cypher có tham số, dùng projection/phân trang và lựa chọn Neo4jClient hoặc Neo4jTemplate khi cần linh hoạt hơn.

Kết thúc lộ trình, bạn có thể xây dựng chức năng đọc–ghi dữ liệu đồ thị, tổ chức ranh giới giao dịch và kiểm thử tích hợp với Neo4j. Trọng tâm là thiết kế mô hình liên kết đúng, hiểu kết quả truy vấn và bảo đảm thao tác dữ liệu hoạt động như kỳ vọng.
