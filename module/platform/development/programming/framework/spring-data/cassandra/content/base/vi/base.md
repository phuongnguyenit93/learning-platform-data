# Spring Data Cassandra

Spring Data Cassandra hỗ trợ ứng dụng Java và Spring truy cập Apache Cassandra bằng cơ chế ánh xạ đối tượng, repository và các API truy vấn. Khác với cơ sở dữ liệu quan hệ, Cassandra được thiết kế cho dữ liệu phân tán và mô hình hóa bảng theo nhu cầu truy vấn. Vì vậy, kiến thức về partition key, clustering columns và CQL là nền tảng để sử dụng Spring Data Cassandra đúng cách.

Roadmap một cấp gồm tám mốc: tìm hiểu Cassandra và CQL, thiết lập kết nối Spring, thiết kế dữ liệu theo truy vấn, ánh xạ entity và khóa, rồi thao tác với repository. Tiếp theo, bạn học query methods, CassandraTemplate, các tùy chọn consistency, TTL và lightweight transactions (LWT). Mốc cuối giúp kiểm thử và nhận diện truy vấn gây tốn kém trên dữ liệu thực tế.

Module phù hợp với người đã biết Java, Spring Boot và nguyên lý cơ sở dữ liệu. Sau khi hoàn thành, bạn có thể thiết kế bảng và entity nhất quán với access patterns, triển khai CRUD và truy vấn có kiểm soát, đồng thời đánh giá các lựa chọn về độ tin cậy và hiệu năng của tầng truy cập dữ liệu.
