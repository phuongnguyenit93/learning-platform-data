# Spring Data JPA

Spring Data JPA hỗ trợ xây dựng tầng truy cập dữ liệu cho ứng dụng Java bằng cách kết hợp mô hình thực thể JPA với cơ chế Repository của Spring Data. Công cụ này giảm mã CRUD lặp lại, hỗ trợ truy vấn theo tên phương thức hoặc JPQL, đồng thời cho phép phân trang, lọc động và quản lý giao dịch theo nhu cầu nghiệp vụ.

Module phù hợp với người đã biết Java, SQL và khái niệm cơ bản về Spring. Lộ trình bắt đầu từ entity và quan hệ, tiếp tục với JpaRepository, các kiểu truy vấn, paging, projection và Specification. Sau đó, bạn học cách đặt ranh giới giao dịch, xử lý khóa khi cập nhật, kiểm soát N+1 và fetch dữ liệu, rồi bổ sung auditing cùng kiểm thử Repository. Kết thúc module, bạn có thể triển khai tầng persistence rõ ràng, kiểm tra được và có ý thức về hiệu năng.
