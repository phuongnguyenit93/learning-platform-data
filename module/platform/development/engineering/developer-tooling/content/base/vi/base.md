# Developer Tooling

Developer Tooling là tập hợp công cụ và kỹ năng giúp lập trình viên thiết lập môi trường, viết và chạy mã, tìm lỗi, kiểm tra kết quả và phối hợp thay đổi một cách hiệu quả. Module tập trung vào thực hành với terminal, IDE/editor, Git, debugger, công cụ chất lượng mã và HTTP/API trong công việc phát triển hằng ngày.

Người học nên có kiến thức lập trình cơ bản và một dự án nhỏ để thực hành. Lộ trình bắt đầu từ cài đặt công cụ và làm chủ workspace, tiếp tục với thao tác dòng lệnh, biên tập mã, quản lý phiên bản, gỡ lỗi, chuẩn hóa chất lượng, kiểm tra API và quy trình cộng tác.

Sau khi hoàn thành, bạn có thể tự chuẩn bị môi trường phát triển, điều tra lỗi bằng debugger, kiểm tra yêu cầu HTTP và chia sẻ thay đổi mã nguồn qua Git và pull request. Các bước được thiết kế theo hướng áp dụng được cho Java cũng như nhiều ngôn ngữ và nền tảng khác.
