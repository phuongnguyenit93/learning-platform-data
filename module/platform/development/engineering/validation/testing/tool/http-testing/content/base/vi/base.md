# Engineering Validation Testing Tool Http Testing

HTTP Testing là kỹ năng xác minh cách một dịch vụ xử lý request và trả response qua giao thức HTTP(S). Bên cạnh việc gọi thử một endpoint, người học cần kiểm tra **method, status code, headers, body, authentication và contract dữ liệu**, cũng như tình huống lỗi và giới hạn đầu vào. Các công cụ như `curl`, Postman, REST Assured, Playwright API và k6 phục vụ những mục đích khác nhau: khám phá và gỡ lỗi thủ công, kiểm thử hồi quy tự động hoặc quan sát phản hồi khi có tải.

Module phù hợp với lập trình viên backend, QA automation và kỹ sư DevOps đã biết kiến thức cơ bản về HTTP và JSON. Lộ trình bắt đầu từ request/response và cách gửi lệnh qua `curl`, tiếp theo là tổ chức Postman collection, xác thực bằng token/cookie và viết assertion cho response. Bạn sẽ học cách kiểm thử đầu vào sai, mã lỗi, ranh giới dữ liệu; dùng environment variables, workflow nhiều request và mock API; rồi chuyển những bài kiểm thử lặp lại thành REST Assured, Playwright hoặc Postman CLI chạy trong CI. Phần cuối giới thiệu k6 để đo độ trễ và tỷ lệ lỗi dưới tải nhỏ, có giới hạn.

Hãy thực hành trên API CRUD trong môi trường thử nghiệm được cấp quyền: gửi request tạo–đọc–sửa–xóa, lưu ID để dùng giữa các bước, xác nhận phản hồi thành công và thất bại, rồi chạy lại cùng bộ test tự động. Thử mock dependency trả lỗi và thực hiện một smoke load test trước khi ghi báo cáo. Không đưa token thật vào kho mã hay log, và không chạy bài thử tải lên production nếu chưa được phê duyệt. Sau module, bạn có thể chọn đúng công cụ và tự xây dựng bộ test HTTP rõ ràng, lặp lại được.
