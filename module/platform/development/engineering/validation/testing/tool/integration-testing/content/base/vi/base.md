# Engineering Validation — Integration Testing

Integration Testing kiểm tra sự phối hợp giữa nhiều thành phần của ứng dụng — chẳng hạn HTTP controller, service, database, message broker và API bên ngoài — để phát hiện lỗi cấu hình, mapping, transaction hoặc giao tiếp mà unit test riêng lẻ khó nhìn thấy. Khác với end-to-end test bao quát cả hệ thống đã triển khai, integration test thường chọn **ranh giới tích hợp cụ thể**, kết hợp các thành phần thật cần kiểm chứng với phụ thuộc được mô phỏng có kiểm soát. Công cụ phù hợp giúp kết quả có tính tái lập mà không phụ thuộc môi trường chia sẻ.

Module hướng đến người học Java đã quen JUnit, Spring Boot và thao tác API/SQL cơ bản. Bạn sẽ xác định phạm vi test, sử dụng JUnit Jupiter và Spring Test, kết nối database thực bằng Testcontainers, mô phỏng HTTP dependency bằng WireMock, rồi quản lý fixture để các bài kiểm thử độc lập. Lộ trình tiếp tục với Awaitility cho tác vụ bất đồng bộ, kiểm tra lỗi và phân quyền xuyên lớp, cuối cùng đưa bộ integration test vào CI bằng Maven Failsafe. Hoàn thành module, bạn có thể tạo một bộ kiểm thử tích hợp đáng tin cậy, tìm được lỗi ở ranh giới thành phần và tránh flaky test do dữ liệu hoặc thời điểm thực thi.
