# Apache Ant

Apache Ant là công cụ tự động hóa build dựa trên Java, sử dụng tệp cấu hình XML (thường là `build.xml`) để mô tả các công việc như biên dịch mã nguồn, sao chép tài nguyên, chạy kiểm thử và đóng gói sản phẩm. Ant cho phép dự án tự định nghĩa các bước thực thi thông qua `target` và `task`, phù hợp khi cần kiểm soát chi tiết quy trình build.

Module **Build Tool Ant** giúp người học đi từ cú pháp buildfile và cấu trúc project đến quan hệ phụ thuộc giữa target, cấu hình property, FileSet và classpath. Trên nền tảng đó, bạn sẽ thực hành xây dựng một chuỗi compile–test–package, tìm hiểu cách quản lý thư viện bằng Apache Ivy, tái sử dụng cấu hình và đưa build vào hệ thống CI.

Module phù hợp với người đã biết Java cơ bản và cách chạy lệnh trong terminal. Sau khi học xong, bạn có thể đọc và chỉnh sửa `build.xml`, chạy target cần thiết, giải thích vì sao một bước build thành công hoặc thất bại và duy trì một quy trình Ant đơn giản, rõ ràng.
