# Maven – Công cụ xây dựng dự án Java

Apache Maven là công cụ tự động hóa quá trình build và quản lý phụ thuộc cho dự án Java dựa trên Project Object Model (POM). Thông qua `pom.xml`, Maven chuẩn hóa cấu trúc mã nguồn, thư viện, biên dịch, kiểm thử, đóng gói và phân phối artifact, giúp các thành viên cùng sử dụng một quy trình build nhất quán.

Module phù hợp với người đã có kiến thức Java cơ bản và muốn chủ động xây dựng ứng dụng bằng Maven. Lộ trình bắt đầu từ việc cài đặt, tạo dự án và đọc POM, tiếp đến là dependency, repository, build lifecycle, plugin; sau đó mở rộng sang dự án nhiều module, profiles và settings.

Sau khi hoàn thành, bạn có thể tự cấu hình một dự án Maven, chọn lệnh `mvn` đúng mục đích, xử lý các vấn đề build và dependency thường gặp, thực hiện kiểm thử, đóng gói và chuẩn bị artifact cho pipeline CI.
