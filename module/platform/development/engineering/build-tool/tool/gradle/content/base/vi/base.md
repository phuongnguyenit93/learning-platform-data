# Gradle — Công cụ tự động hóa build

Gradle là công cụ tự động hóa quá trình biên dịch, kiểm thử, đóng gói và phát hành phần mềm. Module này giúp bạn hiểu cách một bản build được mô tả bằng build script, được tổ chức thành các task và được thực thi theo vòng đời của Gradle.

Bạn sẽ bắt đầu với Gradle Wrapper và các tệp cấu hình, sau đó tìm hiểu tasks, plugins, quản lý dependencies và tổ chức dự án nhiều module. Phần cuối tập trung vào kiểm thử, tạo artifact, tối ưu hiệu năng và áp dụng Gradle trong CI.

Sau khi học, bạn có thể đọc và điều chỉnh một build Gradle cơ bản, xác định nguyên nhân một task được thực thi hoặc bỏ qua, và thiết kế quy trình build có thể tái lập cho dự án Java hoặc JVM.
