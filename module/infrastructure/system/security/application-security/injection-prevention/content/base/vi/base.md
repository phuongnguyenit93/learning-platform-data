# Security Application Security Injection Prevention

Injection là nhóm lỗ hổng xuất hiện khi dữ liệu không đáng tin cậy được đưa vào nơi diễn giải cú pháp, khiến truy vấn, câu lệnh hệ điều hành, bộ lọc thư mục hay nội dung trình duyệt mang ý nghĩa ngoài dự định. Các dạng thường gặp gồm SQL/ORM injection, NoSQL operator injection, OS command/argument injection, LDAP/XPath injection và cross-site scripting (XSS). Nguyên tắc phòng ngừa quan trọng nhất là **tách dữ liệu khỏi lệnh**, ưu tiên API an toàn và hiểu rõ *ngữ cảnh* mà mỗi đầu vào đi qua; chỉ lọc ký tự hay escape thủ công thường không đủ bảo vệ.

Module dành cho lập trình viên web/backend và người học AppSec đã biết API, cơ sở dữ liệu và lập trình cơ bản. Lộ trình bắt đầu từ trust boundary, nguồn dữ liệu và điểm diễn giải (source/sink), sau đó thực hành validation/allowlist và truy vấn SQL có bind parameter. Các phần tiếp theo xử lý riêng NoSQL, OS command, LDAP/XPath và XSS vì mỗi interpreter có cơ chế bảo vệ khác nhau: truy vấn tham số hóa, kiểm soát operator, tách đối số, escaping đúng chuẩn hoặc output encoding theo từng ngữ cảnh. Bạn cũng sẽ sử dụng nguyên tắc quyền tối thiểu để giới hạn thiệt hại khi một lớp phòng vệ bị vượt qua.

Hãy thử với ứng dụng Java/API mẫu trong môi trường kiểm thử được phép: rà soát các đoạn nối chuỗi thành truy vấn, thay bằng prepared statements hoặc API driver có kiểm tra kiểu, dùng DOM API an toàn khi hiển thị dữ liệu và bổ sung test hồi quy cho input bất thường. Kết thúc module, bạn có thể nhận diện những đường truyền input rủi ro, chọn biện pháp phòng ngừa phù hợp từng sink và kết hợp code review, SAST và DAST vào chu trình phát triển mà không đánh đồng kiểm tra đầu vào với bảo mật toàn diện.
