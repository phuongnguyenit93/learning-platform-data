# Security Application Security Outbound Request Security

**Outbound Request Security** là việc kiểm soát những kết nối mà ứng dụng chủ động tạo tới API, URL, webhook hoặc dịch vụ bên ngoài. Một tính năng có vẻ đơn giản như tải ảnh theo URL hoặc kiểm tra webhook cũng có thể bị lạm dụng để yêu cầu server truy cập mạng nội bộ, dịch vụ metadata của cloud hoặc chuyển thông tin xác thực tới đích không được phép. Rủi ro tiêu biểu là **Server-Side Request Forgery (SSRF)**; phòng vệ cần kiểm soát cả dữ liệu đầu vào, hành vi của HTTP client và quyền truy cập mạng thực tế.

Module dành cho người đã biết HTTP/HTTPS, DNS, địa chỉ IP, URI và lập trình ứng dụng cơ bản. Bạn sẽ bắt đầu từ nhận diện luồng outbound và ranh giới tin cậy, xây dựng chính sách allowlist cho scheme/host/port và dùng URI parser thay vì kiểm tra chuỗi thủ công. Các mốc tiếp theo tập trung vào phân giải DNS an toàn, ngăn truy cập loopback/private/link-local, giảm rủi ro DNS rebinding, kiểm soát redirect và cấu hình timeout/giới hạn response. Phần cuối bổ sung egress firewall/NetworkPolicy, bảo vệ metadata endpoint, xác minh TLS, giới hạn việc gửi credential và kiểm thử, ghi nhận request không hợp lệ.

Sau tám mốc, bạn có thể phác thảo một quy trình outbound request có kiểm soát, xác định điểm cần từ chối và viết các trường hợp kiểm thử an toàn cho SSRF. **Allowlist hostname đơn lẻ không đủ** nếu DNS có thể đổi đích giữa bước xác minh và kết nối; cần thực thi chính sách trên địa chỉ kết nối thực tế và có lớp chặn egress. Tương tự, bật HTTPS không thay thế việc xác minh đúng hostname/certificate, và không nên chuyển tiếp token tới những đích chưa được tin cậy.
