# Database Data Modeling

**Data Modeling** là quá trình chuyển yêu cầu nghiệp vụ thành cấu trúc dữ liệu có ý nghĩa, nhất quán và có khả năng phát triển lâu dài. Một mô hình tốt không chỉ mô tả những dữ liệu cần lưu mà còn thể hiện quan hệ, định danh, các quy tắc toàn vẹn và cách ứng dụng sẽ đọc hoặc cập nhật dữ liệu. Module **Database Data Modeling** tập trung vào tư duy thiết kế dữ liệu quan hệ, từ mô hình khái niệm đến schema có thể triển khai.

Lộ trình gồm tám mốc: phân tích miền dữ liệu, lập sơ đồ ERD, thiết kế khóa và ràng buộc, chuẩn hóa, chuyển sang mô hình logic, lựa chọn biểu diễn vật lý và index, quản lý thay đổi schema, rồi kiểm chứng và tài liệu hóa. Trọng tâm là giải thích được vì sao tách hay liên kết các bảng, khi nào cần tối ưu theo truy vấn và cách tránh làm sai lệch dữ liệu khi ứng dụng thay đổi.

Module phù hợp với người đã biết bảng, hàng, cột và SQL cơ bản. Sau khi hoàn thành, bạn có thể phác thảo ERD cho một nghiệp vụ nhỏ, ánh xạ các quan hệ thành bảng với khóa phù hợp, kiểm tra các dạng dư thừa phổ biến, đưa ra lựa chọn index và lập kế hoạch migration có kiểm thử.
