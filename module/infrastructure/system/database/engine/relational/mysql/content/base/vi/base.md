# Database Engine Relational MySQL

MySQL là hệ quản trị cơ sở dữ liệu quan hệ phổ biến, sử dụng SQL để lưu trữ, truy vấn và quản lý dữ liệu có cấu trúc. Module **Database Engine Relational MySQL** tập trung vào các kỹ năng thực hành cần thiết để làm việc với MySQL Server, từ thiết kế bảng và xử lý truy vấn đến bảo đảm tính nhất quán, hiệu năng và an toàn dữ liệu.

Lộ trình gồm tám mốc một cấp: kết nối MySQL, thiết kế schema và kiểu dữ liệu, thao tác SQL/CRUD, tối ưu index với EXPLAIN, giao dịch InnoDB, tài khoản và bảo mật, giám sát vận hành, cuối cùng là sao lưu và replication. Người học sẽ thấy rõ mối liên hệ giữa cách thiết kế dữ liệu, hành vi truy vấn và khả năng bảo trì hệ thống khi tải hoặc số lượng người dùng tăng.

Module phù hợp với lập trình viên đã có kiến thức SQL hoặc cấu trúc dữ liệu cơ bản, cũng như người đang xây dựng dịch vụ sử dụng MySQL. Sau khi hoàn thành, bạn có thể tạo schema, viết và kiểm tra truy vấn, sử dụng transaction đúng mục đích, cấp quyền truy cập hợp lý và thực hành một quy trình sao lưu/khôi phục đơn giản.
