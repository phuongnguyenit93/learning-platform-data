# Runtime Network Engine — Netty

**Netty** là framework mạng bất đồng bộ, hướng sự kiện cho Java, hỗ trợ xây dựng client và server hiệu năng cao trên các transport như TCP/UDP. Thay vì gắn một thread chờ đọc cho mỗi kết nối, Netty dùng event loop để nhận và điều phối sự kiện trên nhiều channel. Một kết nối đi qua `ChannelPipeline`, nơi các `ChannelHandler` lần lượt xử lý dữ liệu vào/ra, giải mã giao thức và phản hồi. Mô hình này giúp xử lý nhiều kết nối hiệu quả, nhưng yêu cầu lập trình viên hiểu rõ thread nào đang chạy handler, cách truyền message và thời điểm tài nguyên được giải phóng.

Module dành cho người đã biết Java, socket/networking cơ bản và concurrency. Lộ trình bắt đầu từ non-blocking I/O, cách dùng `Bootstrap`/`ServerBootstrap` để khởi động client/server, rồi đi sâu vào `Channel`, `EventLoop`, `ChannelFuture` và vòng đời kết nối. Bạn sẽ thiết kế pipeline theo hướng inbound/outbound, ghép handler, xử lý exception và dùng codec để tách framing cùng encode/decode khỏi logic ứng dụng. Phần bộ nhớ tập trung vào `ByteBuf`, allocator và cơ chế reference counting: đối tượng được giữ lại phải được release đúng lúc, nếu không có thể gây leak; release quá sớm lại tạo lỗi truy cập bộ đệm đã giải phóng.

Các bài thực hành cuối module xây một server TCP nhỏ, kiểm thử pipeline/handler bằng `EmbeddedChannel`, xử lý timeout và đóng tài nguyên có trật tự. Bạn cũng sẽ học cách không chặn event loop bằng tác vụ dài, theo dõi rò rỉ `ByteBuf` và chẩn đoán lỗi kết nối. Hoàn thành module, bạn có thể giải thích kiến trúc Netty, xây đường đi dữ liệu từ socket đến handler và quay lại, đồng thời quản lý concurrency, bộ nhớ và vòng đời kết nối một cách an toàn.
