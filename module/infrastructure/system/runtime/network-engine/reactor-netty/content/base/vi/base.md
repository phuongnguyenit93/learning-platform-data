# Runtime Network Engine Reactor Netty

**Reactor Netty** là runtime mạng bất đồng bộ, không chặn, xây dựng trên Netty và tích hợp với Reactor để cung cấp HTTP/TCP client và server cho các ứng dụng Java reactive. Nó là nền tảng mạng thường được Spring WebFlux sử dụng, nhưng hiệu năng và độ ổn định phụ thuộc vào cách ứng dụng dùng event loop, connection pool, timeout và tài nguyên I/O. Hiểu runtime này giúp chẩn đoán các vấn đề như blocking trên event loop, pending connection tăng, timeout dây chuyền hoặc tiêu thụ bộ nhớ ngoài heap.

Module dành cho lập trình viên Java backend đã biết HTTP, networking cơ bản và Reactor `Mono`/`Flux`. Lộ trình bắt đầu từ kiến trúc reactive I/O và event loop, sau đó thực hành HTTP/TCP client-server, cấu hình `ConnectionProvider`, quản lý vòng đời tài nguyên và đặt timeout phù hợp. Bạn sẽ tìm hiểu TLS, DNS/proxy, xử lý lỗi và retry, rồi tích hợp với Spring Boot/WebFlux. Phần vận hành tập trung vào Micrometer metrics, tracing, logging có kiểm soát và load test để điều chỉnh thread, pool, timeout dựa trên số đo thay vì phỏng đoán.

Bài thực hành gợi ý là một ứng dụng WebFlux gọi một dịch vụ HTTP bên ngoài: tạo endpoint reactive, cấu hình `WebClient` dùng Reactor Netty, đặt giới hạn connection pool và timeout, bật metrics rồi giả lập upstream chậm hoặc ngắt kết nối. Quan sát active/pending connections, event-loop tasks và latency khi tăng tải; thử tách tác vụ blocking khỏi event loop và kiểm tra shutdown có giải phóng tài nguyên. Kết thúc module, bạn có thể cấu hình và vận hành Reactor Netty client/server, nhận diện nghẽn I/O và tối ưu runtime theo mục tiêu độ trễ, thông lượng và mức sử dụng tài nguyên.
