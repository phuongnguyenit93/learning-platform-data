# Network Protocol HTTP

HTTP (Hypertext Transfer Protocol) là giao thức tầng ứng dụng giúp client và server trao đổi yêu cầu, phản hồi trên web và trong hệ thống API. Hiểu HTTP là nền tảng để thiết kế giao tiếp giữa các dịch vụ, đọc kết quả trả về và phân tích lỗi khi ứng dụng hoạt động qua mạng.

Module này dành cho người học lập trình web, backend hoặc hạ tầng mạng. Nội dung tập trung vào mô hình request/response, URI và phương thức, cấu trúc thông điệp, mã trạng thái, headers, cookie và phiên làm việc, HTTPS/CORS, cơ chế cache và sự khác biệt cơ bản giữa HTTP/1.1, HTTP/2, HTTP/3. Trọng tâm là hiểu đúng ngữ nghĩa và quan sát luồng dữ liệu thực tế, không đi sâu vào triển khai giao thức ở mức gói tin.

Lộ trình gồm tám mốc ngắn, từ nguyên lý HTTP đến cách kiểm tra bằng `curl` hoặc công cụ mạng trong trình duyệt. Sau khi học, bạn có thể đọc, tạo và chẩn đoán yêu cầu HTTP phổ biến, đồng thời lựa chọn cách dùng phương thức, mã trạng thái và header phù hợp với tình huống.
