# Observability Tracing Tooling Jaeger

Jaeger là nền tảng distributed tracing mã nguồn mở dùng để thu thập, lưu trữ, tìm kiếm và trực quan hóa trace của các hệ thống phân tán. Một trace mô tả hành trình của request qua nhiều service bằng các span có quan hệ nhân quả; trace context được truyền giữa các thành phần để liên kết thời gian xử lý và lỗi. Trong kiến trúc Jaeger hiện hành, ứng dụng thường được instrument bằng OpenTelemetry API/SDK và gửi dữ liệu qua OTLP; Jaeger đảm nhiệm vai trò backend tiếp nhận, xử lý, lưu trữ và cung cấp giao diện truy vấn. Jaeger v2 được xây dựng trên framework OpenTelemetry Collector, vì vậy pipeline receiver, processor, exporter và extension là nền tảng quan trọng để hiểu cách triển khai.

Roadmap một cấp gồm tám mốc: nắm mô hình trace/span và context propagation; instrument ứng dụng bằng OpenTelemetry; nhận diện kiến trúc các vai trò Jaeger v2. Người học tiếp tục chạy all-in-one để thực hành, cấu hình pipeline YAML và query service, lựa chọn storage backend, tìm kiếm trace trên UI, rồi kiểm soát sampling và xử lý dữ liệu bằng các processor. Các mốc cuối tập trung vào triển khai production có khả năng mở rộng, giám sát accepted/refused/sent spans và điều tra sự cố khi mất dữ liệu hoặc latency tăng. All-in-one với memory storage phù hợp thử nghiệm; môi trường production cần backend lưu trữ bền vững và cấu hình vận hành tương ứng.

Module phù hợp với Java/backend developer, SRE hoặc người vận hành hệ thống đã biết HTTP, microservices và các khái niệm observability cơ bản. Sau khi hoàn thành, bạn có thể instrument một luồng request, gửi trace tới Jaeger qua OTLP, tìm và phân tích trace trên UI, lựa chọn sampling/storage hợp lý và kiểm tra pipeline khi telemetry không tới được backend.
