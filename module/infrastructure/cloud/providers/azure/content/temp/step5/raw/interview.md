Một ứng dụng cho phép nhân viên đăng nhập bằng Microsoft Entra ID và cần đọc bí mật trong Azure Key Vault mà không lưu thông tin xác thực trong mã nguồn; bạn sẽ phối hợp Azure RBAC, managed identity và nguyên tắc đặc quyền tối thiểu như thế nào?
Với ứng dụng web ba tầng có giao diện công khai nhưng cơ sở dữ liệu chỉ được truy cập nội bộ, bạn sẽ bố trí Azure Virtual Network, subnet, Network Security Group, Application Gateway và Private Endpoint như thế nào để kiểm soát luồng mạng?
Khi triển khai một API dài hạn, một tác vụ xử lý sự kiện ngắn và nhiều microservice, bạn sẽ chọn giữa Azure Virtual Machines, App Service, Azure Container Apps, AKS và Azure Functions dựa trên tiêu chí quản trị, độ linh hoạt, mở rộng và chi phí nào?
Một hệ thống bán hàng trên Azure thường ít truy cập nhưng tăng tải đột biến và phải chịu được sự cố một availability zone; bạn sẽ thiết kế cân bằng tải, autoscale, health probe và phân bổ năng lực tính toán ra sao để đáp ứng mục tiêu sẵn sàng?
Một nền tảng cần lưu ảnh sản phẩm, ổ dữ liệu của máy ảo và thư mục chia sẻ giữa nhiều máy chủ; bạn sẽ phân biệt Azure Blob Storage, Azure Managed Disks và Azure Files theo kiểu truy cập, độ trễ, khả năng chia sẻ và giá thành như thế nào?
Ứng dụng đặt hàng yêu cầu giao dịch nhất quán trong khi hệ thống ghi nhận hành vi người dùng cần xử lý lượng lớn bản ghi linh hoạt; bạn sẽ so sánh Azure SQL Database với Azure Cosmos DB và xác định chiến lược phân vùng, mở rộng, sao lưu như thế nào?
Một hệ thống lưu hợp đồng khách hàng trong Azure Blob Storage cần ngăn tải xuống trái phép nhưng vẫn cho phép chia sẻ có thời hạn; bạn sẽ kết hợp quyền truy cập, SAS, mã hóa, Private Endpoint, versioning và chính sách vòng đời như thế nào?
Khi ảnh được tải lên Blob Storage, hệ thống cần tạo ảnh thu nhỏ và gửi thông báo bất đồng bộ; bạn sẽ phối hợp Event Grid, Azure Functions và Service Bus ra sao để chịu được lỗi tạm thời, sự kiện gửi lặp và thời điểm xử lý tăng đột biến?
Sau khi phát hành phiên bản mới, người dùng báo API chậm nhưng tài nguyên máy chủ chưa quá tải; bạn sẽ sử dụng Azure Monitor, Application Insights và Log Analytics để liên kết metrics, logs, traces, đặt cảnh báo và xác định nguyên nhân như thế nào?
Nếu một availability zone ngừng hoạt động hoặc dữ liệu production bị xóa nhầm, bạn sẽ lựa chọn giải pháp dự phòng, Azure Backup, Azure Site Recovery và kiểm thử phục hồi theo RTO/RPO như thế nào để bảo đảm ứng dụng tiếp tục phục vụ?
Khi nhiều nhóm cùng triển khai hạ tầng Azure và hóa đơn tháng đầu vượt dự toán, bạn sẽ dùng Bicep, kiểm soát thay đổi, tag, Azure Cost Management và budget alert như thế nào để giảm sai lệch cấu hình và tối ưu chi phí mà không ảnh hưởng mức phục vụ?
